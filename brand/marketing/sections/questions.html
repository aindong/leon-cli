What does leon cost?

Nothing. It is free software under the MIT license.

Does it run on Linux?

The command and its server do. Leon.app needs macOS 11 or later.

What happens to leon when I quit the app?

Your programs keep running, and the app opens on them again. If the server stops, the layout returns with fresh shells.

Is leon fast with many agents?

cat runs at about 117 MB/s, near the macOS limit. An agent pane's history takes about 3 MiB, 90% less than before.

Why does macOS warn me about Leon.app?

It is not notarized yet. Run xattr -dr com.apple.quarantine /Applications/Leon.app once first.
