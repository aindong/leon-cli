Opens a pane for your tests

The agent runs them beside itself, waits for the exit and reads the last lines.

# a pane for the tests
id=$(leon split --label tests \
  --keep-open -- cargo test)

# wait, then read the end
leon wait "$id"
leon capture -b "$id" --trim | tail -2
test result: ok. 18 passed; 0 failed

Starts agents and hears back

Workers get their own tab or worktree. Their reports land in your inbox.

leon agent start --label tests
leon agent start --label docs
I'll wait for their reports.
