# 앱 단축키

Leon.app의 키입니다. [README](README.md#앱-단축키)에서 이어집니다. 바꾸는 방법은 [lua/keys.md](../../lua/keys.md)에 있습니다.

| 키 | 동작 |
|---|---|
| ⌘N | 새 세션 |
| ⌘T | 새 탭 |
| ⌘D | 오른쪽으로 분할 |
| ⌘⇧D | 아래로 분할 |
| ⌘⌥←, ⌘⌥→, ⌘⌥↑, ⌘⌥↓ | 그 방향의 페인으로 포커스 |
| ⌘⇧↩ | 페인 확대(다시 누르면 되돌림) |
| ⌘W | 페인 닫기 |
| ⌘⌥F, ⌘⌥⇧F | 페인을 다른 페인 위에 띄우기, 타일로 되돌리기(헤더를 끌어 옮기고, 가장자리를 끌어 크기 조절) |
| ⌘J | 스크래치 드로어(scratch drawer) 보이기/숨기기: 아래쪽의 셸로, 포커스된 페인의 디렉터리에서 열리며 숨겨져 있는 동안에도 계속 실행됩니다 |
| ⌘⌃←, ⌘⌃→, ⌘⌃↓ | 페인을 왼쪽, 오른쪽, 아래쪽 드로어로 도킹(가장자리를 끌어 크기 조절) |
| ⌘⇧], ⌘⇧[ | 다음 탭, 이전 탭 |
| ⌘1 … ⌘9 | 1–9번 탭으로 이동 |
| ⌘C, ⌘V | 선택 영역 복사, 붙여넣기 |
| ⌘A | 페인의 모든 내용 선택(스크롤백 포함) |
| ⌘F | 페인에서 찾기: ↩와 ⇧↩로 이동, ⌥C 대소문자 구분, ⌥R 정규식, esc로 닫기 |
| ⌘G, ⌘⇧G | 다음, 이전 일치 항목 |
| ⌘⇧C | 복사 모드(Copy Mode): 스크롤백에서 vi 키(h j k l, w b, 0 $, g ⇧G, ⌃U ⌃D), v와 ⇧V로 선택, /와 ?로 검색하고 n과 ⇧N으로 이동, y로 복사, esc나 q로 나가기 |
| ⌘⇧H | 힌트(Hints): 화면의 모든 URL, 경로, 해시, IP, 긴 숫자에 레이블이 붙습니다. 레이블을 입력하면 복사하고, 대문자로 입력하면 페인에 입력합니다 |
| ⇧PageUp, ⇧PageDown | 한 페이지 뒤로, 앞으로 스크롤 |
| ⌘↑, ⌘↓ | 가장 오래된 줄로 스크롤, 맨 아래로 돌아가기 |
| ⌘B | 사이드바 보이기/숨기기 |
| ⌘⇧S | 탭을 사이드바에 둘지 제목 표시줄에 둘지(다음 실행에도 유지) |
| ⌘⇧P | 명령 팔레트: 입력해 액션을 찾고, ↩로 실행, esc로 닫기 |
| ⌘, | 설정(Settings): 모든 설정을 섹션별로 보여 주며 검색 가능, ↑와 ↓로 섹션 사이 이동, esc나 ⌘W로 닫기(init.lua에 기록) |
| ⌘⇧T | 테마 바꾸기. 이동하는 대로 바로 보여 주며, ↩로 유지, esc로 되돌리기 |
| ⌘K | 어떤 호스트 › 세션 › 탭(또는 제목으로 블록)으로든 전환: ↩로 이동, ⌘↩로 이 페인 옆으로 옮기기(같은 머신에서만) |
| ⌘⇧A | 활동(Activity): 모든 호스트에서 내 확인이 필요한 모든 블록(응답 대기, 오류, 완료, 작업 중). 클릭하면 그곳으로 이동 |
| ⌘⇧\, ⌘\ | 개요(Overview): 모든 탭(⌘\는 이 세션의 탭)을 실시간으로. 화살표와 ↩로 이동, 입력으로 거르기, 탭 위에 머무르면 미리 보기 |
| ⌘=, ⌘⇧=, ⌘-, ⌘0 | 글자 크게, 크게, 작게, 기본 크기(보이는 페인) |
| ⌘Q | 종료. 모든 프로그램은 계속 실행됩니다(leon › 종료하고 모든 세션 끝내기(Quit and End All Sessions…)로 끝냅니다) |

![개요(⌘⇧\\): 모든 세션의 모든 탭이 상태와 함께 실시간 타일로 표시됩니다](../../images/app-overview.png)

이것들은 기본값입니다. `init.lua`에서 `leon.bind`로 키를 하나씩 바꾸고 `leon.unbind`로 지울 수 있습니다(⌘Q는 남습니다). `ctrl+b>c` 같은 키 시퀀스는 다음에 누를 수 있는 키를 힌트로 보여 줍니다. 모든 버튼은 마우스를 올리면 액션과 단축키를 보여 줍니다. 휠로 페인의 스크롤백을 거슬러 올라갈 수 있고, 끌어서 선택, option+끌기로 사각형 선택, ⌘를 누른 채 링크를 클릭하면 열립니다. 마우스를 요청하는 프로그램(편집기나 `htop`)은 클릭과 휠을 받습니다. 그래도 선택하려면 shift를 누른 채로 하세요.
