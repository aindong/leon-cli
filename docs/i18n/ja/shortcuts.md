# アプリのショートカット

Leon.app のキーです。[README](README.md#アプリのショートカット) の続きです。変更方法は [lua/keys.md](../../lua/keys.md) にあります。

| キー | 動作 |
|---|---|
| ⌘N | 新しいセッション |
| ⌘T | 新しいタブ |
| ⌘D | 右に分割 |
| ⌘⇧D | 下に分割 |
| ⌘⌥←, ⌘⌥→, ⌘⌥↑, ⌘⌥↓ | その方向のペインにフォーカス |
| ⌘⇧↩ | ペインをズーム（もう一度で元に戻す） |
| ⌘W | ペインを閉じる |
| ⌘⌥F, ⌘⌥⇧F | ペインをほかのペインの上にフロートさせる、タイルに戻す（ヘッダーをドラッグして移動、端をドラッグしてサイズ変更） |
| ⌘J | スクラッチドロワー（scratch drawer）の表示・非表示: 下部のシェルで、フォーカス中のペインのディレクトリで開き、隠している間も動き続けます |
| ⌘⌃←, ⌘⌃→, ⌘⌃↓ | ペインを左、右、下のドロワーとしてドッキング（端をドラッグしてサイズ変更） |
| ⌘⇧], ⌘⇧[ | 次のタブ、前のタブ |
| ⌘1 … ⌘9 | タブ 1〜9 に移動 |
| ⌘C, ⌘V | 選択範囲をコピー、ペースト |
| ⌘A | ペインの中身をスクロールバックも含めてすべて選択 |
| ⌘F | ペイン内を検索: ↩ と ⇧↩ で移動、⌥C で大文字小文字を区別、⌥R で正規表現、esc で閉じる |
| ⌘G, ⌘⇧G | 次の一致、前の一致 |
| ⌘⇧C | コピーモード（Copy Mode）: スクロールバック上で vi のキー（h j k l、w b、0 $、g ⇧G、⌃U ⌃D）、v と ⇧V で選択、/ と ? で検索して n と ⇧N で移動、y でコピー、esc か q で抜ける |
| ⌘⇧H | ヒント（Hints）: 画面上のすべての URL、パス、ハッシュ、IP、長い数字にラベルが付きます。ラベルを入力するとコピー、大文字で入力するとペインに入力 |
| ⇧PageUp, ⇧PageDown | 1 ページ戻る、進む |
| ⌘↑, ⌘↓ | 一番古い行までスクロール、一番下に戻る |
| ⌘B | サイドバーの表示・非表示 |
| ⌘⇧S | タブをサイドバーに置くかタイトルバーに置くか（次回の起動時にも保持） |
| ⌘⇧P | コマンドパレット: 入力してアクションを探し、↩ で実行、esc で閉じる |
| ⌘, | 設定（Settings）: すべての設定をセクションごとに表示、検索あり、↑ と ↓ でセクション間を移動、esc か ⌘W で閉じる（init.lua に書き込み） |
| ⌘⇧T | テーマの変更。移動するとその場でプレビューされ、↩ で決定、esc で元に戻す |
| ⌘K | 任意の ホスト › セッション › タブ（またはタイトルでブロック）に切り替え: ↩ でそこへ移動、⌘↩ でこのペインの隣に移動（同じマシンのみ） |
| ⌘⇧A | アクティビティ（Activity）: すべてのホストで対応が必要なブロック（対応待ち、エラー、完了、作業中）。クリックでそこへ移動 |
| ⌘⇧\, ⌘\ | オーバービュー（Overview）: すべてのタブ（⌘\ はこのセッションのもの）をライブで表示。矢印キーと ↩ で移動、入力で絞り込み、タブの上で止まるとプレビュー |
| ⌘=, ⌘⇧=, ⌘-, ⌘0 | 文字を大きく、大きく、小さく、デフォルトのサイズに（表示中のペイン） |
| ⌘Q | 終了。すべてのプログラムは動き続けます（leon › 終了してすべてのセッションを閉じる（Quit and End All Sessions…）で終了させます） |

![オーバービュー（⌘⇧\\）: すべてのセッションのすべてのタブが、状態付きのライブのタイルとして並ぶ](../../images/app-overview.png)

これらはデフォルトです。`init.lua` の `leon.bind` でキーを 1 つずつ置き換え、`leon.unbind` で削除できます（⌘Q は残ります）。`ctrl+b>c` のようなキーシーケンスでは、次に押せるキーのヒントが表示されます。どのボタンも、ホバーするとアクションとショートカットを表示します。ホイールでペインのスクロールバックをさかのぼれます。ドラッグで選択、option+ドラッグで矩形選択、⌘ を押しながらリンクをクリックすると開きます。マウスを要求するプログラム（エディターや `htop`）にはクリックとホイールが届きます。それでも選択したいときは shift を押したまま操作してください。
